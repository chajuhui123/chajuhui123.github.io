### 컬러 선택하기

블로그를 통해 나의 첫인상을 표현하고 싶었다. 활기찬 나, 밝은 나, 도전적인 나.

그래서 이를 표현할 수 있는 '노랑' 으로 나를 표현하고자 했다! 내가 가장 좋아하는 색상이기도 하다.

컬러 조합 구성부터 굉장히 챌린징했다...! 노랑은 자칫하면 진정성이 없고, 너무 밝은 색상이기에 시선이 분산될 가능성이 커서, 어떻게 하면 정보가 잘 전달되면서도 포인트 색상은 보이게 설계가능할지 고민했다. '나의 추구미 표현 + 정보 전달' 모두를 갖춘 색 조합을 고민했다.

주요 색상 : 서비스의 브랜드 아이덴티티를 확실하게 전달하는 메인 색상
보조 색상 : 주요 색상을 보완하면서 디자인의 균형과 조화를 만들어 주는 색상
기본 색상 : 앱 전반의 배경이나 넓은 영역에 사용되어 전체 분위기의 기초를 만드는 색상
강조 색상 : CTA(Call To Action,콜 투 액션) 버튼이나 사용자 주의를 끌어야 하는 부분에서 시선을 집중시키는 색상
조화로운 색 구상하는 비율 60% : 30% : 10% (기본 색상 : 주요 색상 : 강조 색상)
