## 소제목은 이렇게

본문은 이렇게 [코랄 포인트 컬러를 가진 링크](https://nextjs.org)와 함께 표시됩니다. 인라인 코드는 `pnpm build`처럼 씁니다.

### 리스트도 확인

- 순서 없는 목록 항목입니다.
- 두 번째 항목입니다.

1. 순서 있는 목록입니다.
2. 두 번째 항목입니다.

> 인용문은 왼쪽 보더로 본문과 구분됩니다.

코드 블록은 아래처럼 렌더링됩니다.

```tsx
export function Hello() {
  return <div>Hello, world!</div>;
}
```

| 그룹 성격                       | 해당 파일 예시                         | 커밋 전략                           |
| ------------------------------- | -------------------------------------- | ----------------------------------- |
| 구조 리팩토링                   | 파일 이동/삭제/rename, 디렉터리 재구성 | 선행 커밋, 다른 변경의 기반         |
| 공유 모델/타입                  | `shared/models/`                       | 기능별 독립 커밋                    |
| 공유 UI 컴포넌트                | `shared/ui/`                           | 기능별 분리                         |
| 비즈니스 로직 + 서비스 컴포넌트 | `*/lib/`, `*/components/`              | 동일 기능이면 하나로 묶기           |
| 독립 소기능                     | 단일 파일 수정                         | 성격이 비슷한 것과 묶거나 단독 커밋 |
